# 🚀 Venkatesh Portfolio

A modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS. Showcasing skills, projects, and professional experience with beautiful animations and mobile-first design.

## ✨ Features

- **Modern Design**: Clean, professional UI with dark/light theme support
- **Responsive**: Mobile-first design that works on all devices
- **Animations**: Smooth animations powered by Framer Motion
- **Performance**: Optimized with Vite for fast loading
- **Accessibility**: Built with accessibility best practices
- **Contact Form**: Working contact form with EmailJS integration

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS + Radix UI
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **Forms**: React Hook Form + Zod validation
- **Icons**: Lucide React + React Icons
- **Email**: EmailJS

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/lahori-venkatesh/venkateshportfolio.git
cd venkateshportfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## 📝 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run check` - Type check with TypeScript

## 🎨 Customization

### Theme Configuration

The project uses a custom theme system with CSS variables. You can modify the theme in:
- `theme.json` - Primary colors and appearance
- `src/index.css` - CSS custom properties
- `tailwind.config.ts` - Tailwind configuration

### Content Updates

Update your personal information in:
- `src/components/HeroSection.tsx` - Personal introduction
- `src/components/SkillsSection.tsx` - Skills and technologies
- `src/components/Experience.tsx` - Work experience
- `src/components/ProjectsSection.tsx` - Portfolio projects
- `src/components/Achievements.tsx` - Certifications and awards

### Contact Form Setup

To enable the contact form:
1. Create an account at [EmailJS](https://www.emailjs.com/)
2. Update the EmailJS configuration in `src/components/Contact.tsx`
3. Replace the service ID, template ID, and public key
